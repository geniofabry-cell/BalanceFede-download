# BalanceFede

Entrate, spese e budget personali sotto controllo. App gratuita per **Windows 10 e 11 (64 bit)**, della stessa famiglia di [NoteFede](https://notefede.date/).

**[Scarica l'ultima versione](https://github.com/geniofabry-cell/BalanceFede-download/releases/latest)** · [Pagina dell'app](https://notefede.date/balancefede)

- `BalanceFede-Setup-x.y.z.exe`: installer (consigliato), con collegamenti sul desktop e nel menu Start. Si aggiorna da solo.
- `BalanceFede-x.y.z-portable.exe`: si avvia senza installazione.

Al primo avvio Windows può mostrare "Windows ha protetto il PC": clicca **Ulteriori informazioni → Esegui comunque** (l'app non ha una firma digitale a pagamento). Poi entra con il tuo account **Google** o **Discord**: serve solo a riconoscerti.

**I tuoi dati restano sul tuo computer** (`%APPDATA%\BalanceFede`): nessun server, nessuna sincronizzazione online, nessun collegamento alla banca. Puoi esportarli in CSV o cancellarli dalle Impostazioni.

Problemi o domande? Apri una [segnalazione](https://github.com/geniofabry-cell/BalanceFede-download/issues).
